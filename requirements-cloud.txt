# Dependencias para correr el TP en Cloud Shell (o en cualquier nodo de GCP).
#
# POR QUE EXISTE ESTE ARCHIVO Y NO SE USA requirements.txt
#
# requirements.txt esta pinneado a wheels cp314 porque en local se corre con Python
# 3.14.3. Cloud Shell trae otro Python (3.12/3.13 segun la imagen del dia), y para
# varias de esas versiones exactas no hay wheel: pip intentaria compilar numpy y
# pandas desde el fuente y la sesion se cae por tiempo o por memoria.
#
# Aca las versiones van con COTA, no clavadas. Es un intercambio consciente:
#   - en LOCAL manda requirements.txt, que es reproducible al dígito y es el que
#     firma el `lib_versions` del metadata.json de cada modelo;
#   - en la NUBE manda este, que es instalable, y por eso el modelo se SUBE
#     entrenado desde local en vez de reentrenarse arriba (ver gcp/runbook.md).
#
# Si algun dia se quiere reproducibilidad exacta en la nube, el camino no es pinnear
# esto: es una imagen de contenedor con el mismo Python y el mismo requirements.txt.
